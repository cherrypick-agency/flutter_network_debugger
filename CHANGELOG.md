# Changelog

All notable changes to this project will be documented in this file.

## [0.1.13] - 2025-12-29

### Added
- **Selectable text in JSON Tree viewer** — теперь можно выделять и копировать текст в режиме просмотра JSON-дерева (Response → Tree)
- **Copy all headers button** — кнопка копирования всех хедеров в секции Headers (Request/Response → Info)

### Fixed
- JSON Tree: клик по ключу/значению снова раскрывает/сворачивает вложенные объекты
- JSON Tree: клик по закрывающей скобке `}` / `]` теперь тоже сворачивает узел

## [0.1.12] - 2025-12-28

### Added
- Initial public release
