### План доработок фронта (Compose / общий UI)

#### UX и удобство
- Улучшить drop‑zone: визуальная подсветка при drag over, статус загрузки, показ веса файла.
- Кнопки быстрого добавления популярных заголовков (Content-Type, Authorization, Accept).
- Шаблоны для Body (JSON пример, form примеры), подсказки по форматам.
- Состояние "отправляется" на кнопке Send с индикатором прогресса.
- Копирование CURL для текущего запроса (иконка рядом с Send).

#### Редакторы и валидация
- JSON: подсветка ошибок, автоподсказки (минимум проверка на валидность перед отправкой).
- Headers/Query/Form: валидация пустых ключей, подсветка дубликатов.
- Multipart: лимит по размеру (читать с бэка `COMPOSE_MAX_UPLOAD_MB`), предупреждение и подсветка превышения.
- Автоматическая установка `Content-Type` в зависимости от Body (с возможностью ручного override).

#### Дерево библиотеки
- Контекстное меню: переименование, дублирование, удаление, перемещение между папками (drag & drop внутри дерева).
- Поиск по библиотеке (фильтр по имени/методу/URL).
- Индикатор несохранённых изменений у выбранного шаблона (dirty state).

#### История и интеграция с инспектором
- История отправок (локально в UI + чтение с бэка): быстрый переход к последнему результату.
- Открыть связанную сессию инспектора в один клик (по `sessionId`).

#### Горячие клавиши
- Cmd/Ctrl+Enter — отправить запрос.
- Cmd/Ctrl+S — сохранить шаблон.
- Esc — снять фокус/закрыть выплывающие меню.

#### Производительность
- Виртуализация списков (headers/query/form/multipart) при большом количестве элементов.
- Дебаунс сохранения шаблонов/библиотеки, батч‑сохранение.

#### Тема и доступность
- Фокус‑стили и контраст для всех интерактивных элементов.
- Читабельные сообщения об ошибках/валидации (aria‑friendly текст).

#### Обработка ошибок
- Нормализовать вывод ошибок сети (таймауты, TLS, DNS), показать дружелюбные тексты.
- Показать лимиты/ограничения (размер файла, превью), подсказки как исправить.

#### Настройки
- Переключатель авто‑установки заголовков (например, `Content-Type` для JSON/form/multipart).
- Переключатель pretty/pretty+wrap для ответа.

#### Тесты
- Widget‑тесты редакторов (headers/query/body/auth), проверки валидации.
- Интеграционные тесты отправки запроса (моковый сервер) и отображения ответа.

#### Технический долг
- Выделить подвиджеты для каждой зоны Body (уже частично), стабилизировать API пропсов.
- Централизовать типы/DTO: одна точка импорта и фабрики fromJson/toJson.
- Привести к единому стилю spacing/отрисовки инпутов (InputDecorationTheme).

#### DnD (улучшения)
- Отображать предпросмотр имени/размера/типа файла.
- Кнопка очистки выбранного файла и быстрая замена.
- Поддержка множественных частей‑файлов в multipart (массовый drop).

#### Качество жизни
- Сохранение и восстановление последнего состояния формы (локально в prefs).
- Автосохранение черновика при переключении между шаблонами (с confirm при потере изменений).

#### Документация и помощь
- Встроенные короткие подсказки (tooltip/`?`) возле сложных полей.
- Раздел справки по Compose (клавиатура, лимиты, примеры).
